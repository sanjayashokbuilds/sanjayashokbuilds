## ⏱️ 24-hour builds

Right now I'm doing a series of 24-hour builds: picking a real problem, building a working solution from scratch in 24 hours, and shipping it. The goal is to get faster, sharper and more efficient every time.

| # | Project | What it does | Link |
|:-:|---|---|:-:|
| 1 | **Life-hours** | Shows students what their spending really costs, measured in hours of their life. Every purchase is converted into hours through a time-plus-money opportunity-cost model, with regret tracking and automatic logging of Apple Pay payments. | [Live app](https://life-hours.netlify.app) · [Code](https://github.com/sanjayashokbuilds/invisible-costs) |
| 2 | **Chola-dates** | Works out the real dates of medieval Indian temple inscriptions, which recorded time by the sun, moon and stars. Built on a Swiss Ephemeris astronomical solver and a Bayesian model that jointly infers a king's accession date (6 July 1178) and which inscriptions were miscarved, with 53 automated tests. | [Live app](CHOLA_LIVE_URL) · [Code](https://github.com/sanjayashokbuilds/chola-dates) |
| 3 | **Chit-options** | Works out what a seat in a Tamil chit fund is worth and when members should bid for the pot. Prices each seat as an American option with dynamic programming and Longstaff–Schwartz Monte Carlo, solves the bidding game's Nash equilibrium, and calibrates to real chit-company data, with a playable version running Python in the browser via Pyodide. | [Live app](https://chit-options.netlify.app) · [Code](https://github.com/sanjayashokbuilds/chit-options) |

**Stack so far:** Python · NumPy · pandas · pytest · Bayesian inference · Monte Carlo · Dynamic programming · Swiss Ephemeris · Streamlit · Plotly · Pyodide · JavaScript
